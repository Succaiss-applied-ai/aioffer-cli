# 迁移与验收说明

## 迁移范围

投递执行器基于 AI Offer 招聘插件 `1.0.12`，源提交 `a5693a0ba948897b3b2151c840d7fda458079449`。原站点控件驱动及回归测试携带迁移，不重写一套近似填写逻辑。

本地新增：命令行启动、中文页面、用户自带模型、MinerU、本机文件、不可变简历版本、岗位快照检索、跨模式重复保护。原公司账号、权益校验、云端资料查询及对外回调不参与本地运行。

半自动复用原批次执行器，不启用只供验收的 `localValidation`。原来的停止、租约、受控页中断、提交意图持久化和真实回执分类仍在；首次填写后返回等待确认。确认绑定岗位、当前回读哈希与有效期，普通继续不能代替最终授权。自动模式保留一次授权后逐岗执行。

CLI 产品版本 `0.1.0` 与继承的插件协议版本 `1.0.12` 独立，不以修改最低兼容版本代替能力测试。

## 数据快照

从现有岗位服务导出同一快照，核对总量与唯一岗位 ID，再只保留公开招聘字段：公司、标题、地区、说明、投递地址、渠道、薪酬、标签和验证时间。没有打包 API Token、候选人、设备、表单内部采集、任务日志或回调信息。

原始导出不提交仓库。`scripts/package-catalog.mjs` 仅供维护者处理获得授权的导出文件，用户运行不连接原岗位服务。原内容质量、时效性和版权须按原发布方处理；快照不保证仍可申请。

## 自动化与实站验收分开

| 检查 | 证明什么 | 不证明什么 |
| --- | --- | --- |
| 本地接口测试 | 访问凭据、跨站拦截、资料版本、确认等约束 | 真实模型提取质量 |
| 模型/MinerU 模拟测试 | 请求协议、错误处理与 Key 传输边界 | 每家账号/套餐可调用 |
| 原控件和状态机回归 | 夹具下的路由、回读、租约、中断与回执约束 | 所有招聘网站当前可用 |
| 构建和 doctor | 本地依赖与产物完整 | 插件已配对或真实投递成功 |
| 浏览器页面验收 | 中文页面可加载、搜索和提示可操作 | 完整申请闭环 |

当前仍需验证：用户自己的 MinerU 和视觉模型真实调用、Chrome 解压扩展实际配对、已支持 ATS 的填写与人工交接、半自动最终确认的实页回读、自动模式真实网站回执。真实最终提交需用户针对测试申请另行明确授权。

目前不把这些未验收部分描述为已完成正式发布。保留原路由和实页门禁，候选代码应以草稿 PR 审查。

## 已知限制

- 主项目 `pnpm typecheck` 已通过，但额外对扩展依赖图执行严格 TypeScript 检查时，仍有 10 项上游既存错误。已用同版本独立源快照复核，错误位置与内容一致；不能把主项目类型检查表述为整个扩展严格类型检查通过。原控件驱动目录逐文件对比未修改，这些问题不通过删断言、放宽类型或跳过测试隐藏。

- 资料核对目前为 JSON 编辑器，尚不是完整中文字段表单。
- 本地数据包含明文密钥与敏感简历，不提供同步、钥匙串加密或多用户隔离。
- 岗位是静态快照，不自动采集和更新；部分招聘链接本来就不是可自动填写的官网入口。
- 同岗新建任务保护保守，结果不明确或不可恢复失败不提供直接重投按钮。原等待任务仍按已有登录、验证码、补充资料流程继续。
- 停止、取消或删除本地文件不等于撤回网站申请。
- 上游历史文档中的已成功记录属于原项目，不得包装成本地版的新验收结果。
